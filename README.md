# Coding Practice & Projects

This repository contains my ongoing programming practice and project work while learning software development.

## What is here

- **C, C++, Java and Python** practice programs covering basics, arrays, functions, pointers, recursion, sorting, data structures and problem solving.
- **React project** in [`my-app/`](./my-app), currently focused on text transformation and comparison with live Chart.js visualizations, Bootstrap styling and custom controls.
- Small experiments with Node.js, PHP, HTML/CSS and Tailwind CSS.

## Run the React app

```bash
cd my-app
npm install
npm start
```

The app runs at `http://localhost:3000`.

This is a learning repository, so examples and projects will continue to grow as I practice and build.
